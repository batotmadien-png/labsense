# LabSense — خطوات التشغيل

1. جيبي مفتاح مجاني من console.groq.com/keys ← Create API Key (من غير كارت).
2. ارفعي الفولدر ده كله على GitHub (ده كمان مطلوب في التسليم).
3. ادخلي vercel.com ← سجّلي بحساب GitHub ← Add New Project ← اختاري المستودع.
4. قبل Deploy: Environment Variables ← الاسم GROQ_API_KEY والقيمة هي المفتاح.
5. اضغطي Deploy. هيدّيكي رابط الموقع.

ملاحظة: لو فتحتي index.html مباشرة من الجهاز، الذكاء الاصطناعي مش هيشتغل. لازم يتنشر على Vercel.
